# Bit by Bit

머신러닝의 기초부터 딥러닝, 생성형 AI, AI 시스템까지 원리부터 연결해 기록하는 한국어 스터디 블로그입니다.

## 특징

- 반응형 단일 페이지 홈과 3개의 AI 샘플 학습 노트
- 주제별 필터와 키워드 검색
- 시스템 설정을 따르는 다크 모드 및 수동 전환
- 별도의 빌드 과정 없이 GitHub Pages에서 바로 배포 가능

## 로컬에서 보기

`index.html`을 브라우저에서 열거나 정적 파일 서버를 실행하세요.

```bash
python -m http.server 8000
```

그 다음 `http://localhost:8000`으로 접속하면 됩니다.

## 새 글 추가

1. `posts/` 안의 기존 HTML 파일을 복사합니다.
2. 제목, 메타데이터와 본문을 수정합니다.
3. `index.html`의 `.post-grid`에 새 카드 항목을 추가합니다.

## 배포

GitHub 저장소의 **Settings → Pages**에서 `main` 브랜치의 루트(`/`)를 배포 소스로 선택하면 됩니다.
