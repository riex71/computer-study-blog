# Studybase

AI 공부 내용을 직접 작성하고 관리하는 브라우저 기반 개인 노트 앱입니다.

## 주요 기능

- 노트 작성, 열람, 수정, 삭제
- Markdown 작성 및 실시간 미리보기
- 주제별 분류, 태그, 중요 노트 표시
- 제목·내용·태그 통합 검색과 정렬
- 라이트/다크 테마 및 반응형 화면
- JSON 백업 내보내기와 가져오기

## 데이터 보관 방식

모든 노트는 브라우저의 `localStorage`에만 저장됩니다. 별도 계정이나 서버가 없으며, 다른 브라우저나 기기로 자동 동기화되지 않습니다. 브라우저 데이터를 삭제하면 노트도 사라질 수 있으므로 **내보내기** 기능으로 주기적으로 백업하세요.

## 로컬 실행

정적 파일 서버로 프로젝트 폴더를 열면 됩니다.

```bash
python -m http.server 8000
```

별도의 빌드 과정이나 외부 데이터베이스는 필요하지 않습니다.
